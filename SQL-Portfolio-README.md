## 📊 Skills Demonstrated

### Foundational
- `SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`
- `INNER JOIN`, `LEFT JOIN`, Self JOIN
- Aggregate functions: `COUNT`, `SUM`, `AVG`, `MAX`, `MIN`
- `ISNULL`, `COALESCE`, `CONCAT`, `CAST`
- Subqueries

### Intermediate → Advanced
- `DENSE_RANK()`, `ROW_NUMBER()` — Window Functions
- `HAVING` clause for post-aggregation filtering
- Multi-table JOINs (3+ tables)
- Custom Scalar Functions (`CREATE FUNCTION`)
- Business-context reporting for Sales, HR, Inventory, and Operations
